# 机场订阅链接是什么：凭据、返回内容与重置
更新:2026-11-05 · 依据:开源面板源码

机场订阅链接是带有账号凭据的地址，客户端用它取得节点。链接能关联账号，外传后不能当成只分享了一段普通文字。

## 链接中哪部分对应账号？

地址中的 token 用于找到对应账号。以开源面板 Xboard 为例，各家机场可能改过，以你那家后台显示为准。

允许展示的占位地址是 `https://example.com/s/xxxx`。其中 `s` 对应可配置的前缀，`xxxx` 仅代替 token，不是真实凭据。

| 组成 | 在示例面板中的含义 |
| --- | --- |
| 前缀 | 后台可设置，默认是 s，机场可以改掉 |
| token | 用于定位账号并下发其节点 |
| 旧入口 | 仍保留旧订阅路径 |

默认前缀不等于每家后台都用相同地址。不能把占位地址或某一种入口直接当成你自己的订阅。

## 外传后怎样更换凭据？

后台的「重置订阅」会同时更换 token 与 uuid。前者对应订阅账号凭据，后者关联节点认证，旧链接会失效。

因此重置不只是让地址文字换个样子。节点认证也跟着变化，不能只按原地址仍保存在客户端里就认定它继续有效。

## 同一地址为何返回不同内容？

面板会按格式标记或客户端标识选择输出。客户端标识也叫 User-Agent，用来识别是谁发来请求。

可以返回 Clash Meta、sing-box、小火箭或通用 Base64 等格式。Base64 是编码形式，返回文本不同不直接代表账号不同。

Clash 格式还带 `subscription-userinfo`，用于提供用量、总量和到期信息。另有 `profile-update-interval`，这里写入的值为 24。

## 空白和信息条目是什么？

账号过期或停用时，这套实现返回 403 与空内容。403 是响应状态，页面空白需要与后台账号状态一起核对。

后台还可开启「在节点里显示信息」。订阅前面会增加剩余流量、套餐到期等名称条目，它们复制首个节点，不是另配了一组服务器。

这些条目是展示账号信息的另一种方式。它们与响应头不在同一个位置，不能只看有没有这种节点名，就判断账号没有流量资料。
